# Dotfiles v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land phases O (perf safety net), P (portability), R (lifecycle), Q (automation & upkeep) on top of v1 of the chezmoi overhaul.

**Architecture:** Each phase adds files under its own namespace (`scripts/perf/`, `scripts/maintenance/`, `scripts/doctor/phase-{o,p,r,q}.sh`) and templates existing hardcoded sites against new `.chezmoidata.yaml` keys and `.chezmoi.toml.tmpl` prompts. Doctor coverage grows commit-by-commit; `just doctor` is the single gate.

**Tech Stack:** chezmoi, zsh, bash, launchd, Homebrew, hyperfine, just, pre-commit, GitHub Actions, shellcheck, shfmt.

**Spec:** [`docs/specs/2026-10-03-dotfiles-v2-design.md`](../specs/2026-10-03-dotfiles-v2-design.md)

## Global Constraints

- Every new shell script starts with `#!/usr/bin/env bash` and `set -euo pipefail`.
- Pre-commit runs `shellcheck --severity=warning` and `shfmt -i 2 -d` on all `*.sh`; both must pass.
- `*.sh.tmpl` files are excluded from shellcheck (chezmoi template syntax breaks parsing) — per [`docs/history/2026-07-06-terminal-workflow-plan.md`](../history/2026-07-06-terminal-workflow-plan.md) phase J conventions.
- Conventional-commit messages (`type(scope): subject`); **no auto co-author** (global CLAUDE.md §3).
- Target: macOS Apple Silicon only. Intel is in Future work.
- No `/Users/kulsin`, `kulsin@`, or `singh.kulwant@gmx.com` in any managed file outside `docs/`.
- All `.tmpl` files must `chezmoi execute-template` clean.
- Doctor assertions use `scripts/doctor/lib.sh` helpers: `check`, `pass`, `fail`, `assert_file`, `assert_no_file`, `assert_dir`, `assert_grep`, `assert_no_grep`, `assert_cmd_ok`, `assert_cmd_out`, `assert_perm`, `assert_brew_installed`. Caller invokes `phase_start "<letter>" "<name>"` once and `check "<name>"` before each assertion. `SOURCE="$CHEZMOI_SOURCE"` is standard.
- Shell startup budget: `.chezmoidata.yaml → perf.shell_budget_ms: 200` (steady-state measured 90 ms; 2× headroom).
- Hyperfine invocation: `--warmup 3 --min-runs 10 -N --export-json <tempfile>`.
- Launchd label naming convention: `local.*` (user-free; replaces the `com.kulsin.*` legacy).
- Chezmoi managed-file prefixes: `private_` → mode 600, `dot_` → leading `.`, `.tmpl` suffix → templated. `_` cannot start a dir name; `private_dot_ssh/private_config.tmpl` is the correct path for `~/.ssh/config`.
- Weekly agent default: `automation.weekly_maintenance: false` in `.chezmoidata.yaml`. Opt-in only.

## Review Focus

Five inputs/conditions the spec implies but no task's happy-path tests exercise. Each is pinned by a test added to the owning task.

1. **`scripts/install.sh` re-run on an already-installed machine** — must detect `~/.local/share/chezmoi` exists and run `chezmoi apply` instead of the fresh bootstrap. Owned by **Task 9**; test added to Task 9 Step 2.
2. **`scripts/uninstall.sh --dry-run --purge-data` on a machine missing `~/.local/share/atuin/`** — the data-purge branch must not fail when the directory is absent. Owned by **Task 10**; test added to Task 10 Step 2.
3. **`chezmoi init` with empty prompt answers (Enter-through)** — `name`, `email`, `github_user`, `work` must fall back to the declared defaults, not store empty strings. Owned by **Task 2**; test added to Task 2 Step 2.
4. **Toggling `automation.weekly_maintenance` false→true→false then re-applying** — the run_onchange script must load the agent on true, bootout on false, with no residual plist file. Owned by **Task 14**; test added to Task 14 Step 2.
5. **Phase P grep guard allowlist** — the guard must *not* flag `kulsin` references in `docs/`, in `.git/`, or in `scripts/doctor/phase-p.sh` itself (which has to spell the forbidden strings to search for them). Owned by **Task 7**; test added to Task 7 Step 2.
